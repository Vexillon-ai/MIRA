🛡️ Wazuh Security

MIRA runs the Wazuh manager as a managed container and supervises it. The Guardian watches for the manager going unreachable and triages it. Ask MIRA things like "which devices is Wazuh monitoring?" (the list_agents tool).

Configure the API URL, user, and password under Apps → Wazuh Security. This is an illustrative single-container example; a full Wazuh deployment adds an indexer + dashboard.
