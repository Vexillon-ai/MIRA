Home Assistant

MIRA can read your sensors and control your devices.

Just ask MIRA

  • “What's the temperature in the living room?”
  • “Turn off the kitchen lights.”
  • “Is the garage door open?”
  • “Toggle the office fan.”

Tools MIRA has

  • get_stateread one entity's state + attributes
  • list_statesdiscover entity ids across your home
  • call_servicecontrol a device (turn_on / off / toggle / …)

Setup

  • Set your HA URL (base_url) and a Long-Lived Access Token in this app's settings.
  • The token is stored encrypted and never leaves this host except to reach your HA instance.
Connected through MIRA · calls run via MIRA's SSRF-guarded HTTP layer
